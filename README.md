## About

Fetches feeds, filters unread items and exports a clean digest to a file.

## Features

- Single-file, zero-setup script
- Reads plain JSON input
- Produces clean, readable output
- Works on Python 3.9+

## Install

```bash
git clone https://github.com/nurrabby2024/rssprune.git
cd rssprune
```

## Usage

```bash
python main.py

python main.py input.json -o out.txt -v
```
